# Student Information System

## Project Description

A Python-based Student Information System that manages student records and stores data in JSON format.

## Features

* Add new students
* View all student records
* Search for students
* Update student information
* Delete student records
* Store student data in JSON
* Log application errors and activities
* Validate student information

## Technologies Used

* Python
* JSON
* Visual Studio Code
* Git and GitHub

## Project Structure

* `src/` – Main application, models, services, and utilities
* `data/` – Student data stored in JSON
* `config/` – Application configuration
* `logs/` – Application logs
* `tests/` – Automated tests
* `requirements.txt` – Project dependencies

## How to Run

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the project directory.
4. Run `python -m src.main`.

## How to Run Tests

Run this command from the project directory:

`python -m unittest discover -s tests -v`
